# MK Snake Game

A simple snake game with level progression, life system, poison borders, and hard levels.

## Run locally

Open the `index.html` file in a browser, or serve the folder with a simple local web server.

Example:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Deploy to GitHub Pages

1. Push this folder to a GitHub repository.
2. Go to the repository settings.
3. Open **Pages**.
4. Set **Source** to **Deploy from a branch**.
5. Select the branch, usually `main`.
6. Choose the folder `/root`.
7. Save.
8. GitHub will give you a live URL like:

```text
https://your-username.github.io/your-repository-name/
```

## Mobile support

This game is built to work on phones and tablets using touch buttons for movement.
